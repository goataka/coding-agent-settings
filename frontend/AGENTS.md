# フロントエンドエージェント設定

このファイルは`frontend/`ディレクトリにあるため、このディレクトリ内のファイルに優先的に適用されます。ルートのAGENTS.mdより優先度が高くなります。

## フロントエンド固有のルール

- UIコンポーネントはアトミックデザインパターンに従う
- レスポンシブデザインを必ず考慮する
- ブラウザ互換性を確認する（Chrome, Firefox, Safari, Edge）
- CSSはモジュール化して管理する

## パフォーマンス

- 画像は最適化してから使用する
- Lazy Loadingを活用する
- バンドルサイズを最小限に抑える
